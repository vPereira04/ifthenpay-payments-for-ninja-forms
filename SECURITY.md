# Security Policy

Security contact: [suporte@ifthenpay.com](mailto:suporte@ifthenpay.com)

## Supported versions

Security fixes are released for the latest version of ifthenpay | Payments for Ninja Forms. Please update to the latest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please report security issues privately. Don't use the public WordPress.org support forum or a public issue tracker for them.

- **Email:** [suporte@ifthenpay.com](mailto:suporte@ifthenpay.com), with "Security" in the subject line.

Please include:

- the plugin version, plus your WordPress, Ninja Forms and PHP versions;
- the steps to reproduce the issue, or a proof of concept;
- what an attacker could do with it.

## What happens next

- We confirm we received your report.
- We look into it and keep you posted on progress.
- Once a fix ships, its changelog entry starts with **Security:** so site owners know to update.

Please don't disclose the issue publicly until a fix is available. We're happy to credit you in the changelog if you'd like.
